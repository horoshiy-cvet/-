=== Хороший Цветочный — Сайт ===

Файлы:
  index.html   — главная страница
  catalog.html — каталог букетов + корзина + отправка в Telegram
  img/         — фотографии букетов (bouquet1.jpg … bouquet9.jpg)

ПЕРЕД ПУБЛИКАЦИЕЙ:

1. Откройте catalog.html в любом текстовом редакторе
2. Найдите строки (ближе к концу файла):
     const TELEGRAM_TOKEN = 'ВАШ_ТОКЕН';
     const TELEGRAM_CHAT_ID = 'ВАШ_CHAT_ID';
3. Замените на свои значения:
     - TELEGRAM_TOKEN: получите у @BotFather в Telegram (создайте бота, команда /newbot)
     - TELEGRAM_CHAT_ID: получите у @userinfobot (нажмите Start)
4. Сохраните файл
5. Обязательно напишите своему боту /start в Telegram — иначе он не сможет отправить вам сообщение

ЗАГРУЗКА НА GITHUB PAGES:

1. Создайте репозиторий на GitHub
2. Нажмите Add file → Upload files
3. Перетащите все файлы: index.html, catalog.html и папку img целиком
4. Нажмите Commit changes
5. Зайдите в Settings → Pages → Branch: main → Save
6. Через 1-2 минуты сайт будет доступен по адресу:
   https://ваш-логин.github.io/название-репозитория/

ТЕСТ:

1. Откройте index.html в браузере — должна открыться главная страница
2. Нажмите "Смотреть каталог" — откроется catalog.html
3. Нажмите "В корзину" на любом букете — он добавится
4. Заполните форму и нажмите "Отправить заказ"
5. Если всё настроено правильно — заказ придёт в Telegram
