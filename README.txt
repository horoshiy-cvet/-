Хороший Цветочный — сайт
========================

Структура:
  index.html    — главная страница
  catalog.html  — каталог букетов + корзина + форма заказа
  style.css     — стили (общий для обеих страниц)
  img/          — фото букетов (bouquet1.jpg … bouquet9.jpg)

Перед публикацией:
  1. Открой catalog.html в блокноте
  2. Найди строки (ближе к концу файла):
     var TELEGRAM_TOKEN = 'ВСТАВЬТЕ_ТОКЕН_СЮДА';
     var TELEGRAM_CHAT_ID = 'ВСТАВЬТЕ_CHAT_ID_СЮДА';
  3. Вставь свои значения от @BotFather и @userinfobot
  4. Найди своего бота в Telegram и напиши /start
  5. Загрузи все файлы на GitHub

Как работает:
  - На главной: кнопки «Заказать» добавляют букет в корзину и перекидывают в каталог
  - В каталоге: кнопки «В корзину» добавляют букет и прокручивают к форме
  - Форма отправляет заказ прямо в Telegram
