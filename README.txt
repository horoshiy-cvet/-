ХОРОШИЙ ЦВЕТОЧНЫЙ — САЙТ
========================

Структура:
  index.html    — главная страница
  catalog.html  — каталог букетов + корзина + форма заказа
  style.css     — стили (общий для обеих страниц)
  img/          — фото букетов (bouquet1.jpg … bouquet9.jpg)

ПЕРЕД ПУБЛИКАЦИЕЙ:
1. Откройте catalog.html в блокноте
2. Найдите строки (ближе к концу файла):
     const TELEGRAM_TOKEN = 'ВАШ_ТОКЕН';
     const TELEGRAM_CHAT_ID = 'ВАШ_CHAT_ID';
3. Замените ВАШ_ТОКЕН на токен от @BotFather
4. Замените ВАШ_CHAT_ID на ваш ID от @userinfobot
5. Найдите своего бота в Telegram и нажмите /start
   (без этого бот не сможет вам написать)

ЗАГРУЗКА НА GITHUB:
1. Зайдите в репозиторий → Add file → Upload files
2. Перетащите все файлы и папку img
3. Commit changes
4. Settings → Pages → Branch: main → Save
5. Сайт будет доступен по адресу: логин.github.io/название-репозитория
