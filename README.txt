ИНСТРУКЦИЯ ПО УСТАНОВКЕ
======================

1. РАСПАКУЙТЕ АРХИВ
   Распакуйте файлы в любую папку на компьютере.

2. НАСТРОЙКА TELEGRAM (обязательно!)
   
   а) Создайте бота:
      - Найдите @BotFather в Телеграме
      - Напишите /newbot
      - Придумайте имя и username
      - Скопируйте API Token (длинный код вида 123456:ABC-DEF...)
   
   б) Узнайте свой Chat ID:
      - Найдите @userinfobot в Телеграме
      - Нажмите Start
      - Бот пришлёт Your user ID: 123456789
      - Скопируйте эти цифры
   
   в) Напишите своему боту /start (обязательно!)
   
   г) Откройте файл catalog.html в любом текстовом редакторе
      Найдите строки:
         const TELEGRAM_TOKEN = 'ВАШ_ТОКЕН';
         const TELEGRAM_CHAT_ID = 'ВАШ_CHAT_ID';
      Замените на свои значения:
         const TELEGRAM_TOKEN = '123456:ABC-DEF...';
         const TELEGRAM_CHAT_ID = '123456789';

3. СТРУКТУРА ФАЙЛОВ
   horoshiy-cvet/
   ├── index.html      (главная страница)
   ├── catalog.html    (каталог + корзина + форма)
   ├── style.css       (стили)
   └── img/            (фото букетов)
       ├── bouquet1.jpg
       ├── bouquet2.jpg
       ├── ...
       └── bouquet9.jpg

4. ЗАГРУЗКА НА GITHUB
   а) Создайте репозиторий на github.com (Public)
   б) Add file → Upload files
   в) Перетащите все файлы и папку img
   г) Commit changes
   д) Settings → Pages → Branch: main → Save
   е) Через 1-2 минуты сайт будет доступен по адресу:
      ваш-логин.github.io/название-репозитория

5. ПРОВЕРКА
   - Откройте catalog.html в браузере
   - Добавьте букет в корзину
   - Заполните форму и отправьте
   - Заказ должен прийти в Телеграм
